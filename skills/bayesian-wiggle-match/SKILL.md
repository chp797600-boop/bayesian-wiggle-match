# 贝叶斯树轮 wiggle-match：0.5.0-rc1 规则候选版

这是依据文献独立实现的解析高斯模型，**不是 OxCal，也不是 Pearson 2026 作者代码复现**。数学核对已通过；真实数据仍存在未覆盖真值的案例。0.2改进先验声明、敏感性对照和结果解释，沿用0.1数学内核，未证明定年准确率提高。适合研究、模型检查和候选年代比较，不提供经过可靠性验收的最终考古定年能力。

0.4.0在0.3.0后验集中/候选峰功能上增加固定偏移重叠积分、年代—偏移联合摘要及assessment.py：核实保存运行身份后做逐轮留一、后验预测、显式搜索/参考对照、独立真值评分与模型内模拟覆盖。run自动保存固定偏移一致性及偏移摘要；较重检查需显式调用assessment，不默认启动大量重拟合。数学内核0.1.0字节不变；没有通用OxCal适配器或自动唯一性/五关验收。窄后验和一致性通过都不能代替独立真值检验。

先读 [输入、运行与解释](references/usage.md)。需要说明模型或选择偏移先验时，再读 [模型与适用边界](references/model.md)。已有数据和验证证据见 [数据与验证记录](references/validation.md)。

需要完整模型检查、留一验证、预测或模拟覆盖时，读[模型评估操作](references/assessment.md)，保留所有设定和失败，不根据已知真值选择最优模型。

本候选版仅更新证据判读与偏移先验审查；可执行接口仍0.4.0、数学内核仍0.1.0。正式0.4.0保留，尚未发布正式0.5.0。相关协方差工具不在本包内。

报告前阅读[失败判读与偏移证据](references/failure_and_offset_evidence.md)：分别报告计算完成、诊断条件、独立真值，不给单一“成功”标签。冻结外部验证与严格盲验需分别命名。

## 本项目已安装的初选入口

当前用途是初选。先读[MCP初选流程](references/mcp_screening.md)，优先调用项目服务`bayesian_wiggle_match`，再使用下述原有诊断规则。安装不改变计算内核和可靠性限制。

## 五关判读

解释新匹配或复查可靠性时，阅读[五关判断与报告](references/five_gate_diagnostics.md)，逐项给出证据及状态，不把未评估写成通过。raw材料原三关分别映射为当前第二、三、四关。

|关口|要回答的问题|当前实现状态|
|---|---|---|
|第一关：计算有效性|输入、模型和数值计算是否成立？|已有解析计算及数值对照；参考缺口、边界和MCMC收敛需分别检查|
|第二关：统计一致性|序列在相应模型下是否相容？|原生固定偏移Acomb/An及同模型预测检查；共享未知偏移不套固定公式。参考归一化范围、搜索和软件阶段须核实|
|第三关：唯一性与精度|主峰、HPD结构、局部概率是否支持一个足够窄的年代带？|已有窗口概率及候选峰证据；局部峰/谷部记账盆地不等于已验证年代簇，唯一性仍需尺度与来源判读|
|第四关：偏移合理性|偏移受数据约束、有外部解释，且对合理先验稳健吗？|已算混合等尾区间、年代—偏移关联及方差分解；先验对照保留，物理解释需外证|
|第五关：独立真值|对独立已知年代，是否恢复真实日期？|独立真值只作后验评分；模型内模拟另列，不能代替独立实测验证；未知样品无真值记不适用|

逐关判读不能构成准确性保证；固定零偏移不等于已由数据证实偏移为零。先验、研究所需精度及竞争概率判读依据须在据结果验收前声明，不设通用90% Acomb或“一两年必须占95%”规则。

## 使用规则

- 遵守当前项目约定。原始测量只读；输出及临时文件限用户允许的非 C 盘位置。单代理执行，不上传样品，不修改全局配置。
- 输入必须是北半球陆生树轮、单年取样、精确整数年距。缺失测年可用已知 ring_offset 表达；重复 ring_offset、多年混样、不确定年距、已知批次相关误差或储库修正不属于首版能力，不能通过改字段绕过。
- 用 **14C BP 与 1 sigma 误差**。历年为整数天文年：0=1 BCE，-1=2 BCE。不要把负 BCE 数直接当成天文年。Delta14C 不能直接写入年龄列。
- 建立参考前检查来源、年表独立性、年宽、测量去重及误差口径。只选用户目标对应的树木/实验室，不把全部观测自动混成一条曲线。工具仅检查声明的树木/测量标识是否重叠，不能代替来源审查。
- 使用显式的搜索年窗及有依据的共同偏移先验。0.2的run.py和execute接口必须显式提供偏移标准差（14C BP），无默认科学先验；正偏移表示样品14C年龄比参考更老。core.match保留旧数值接口，不能通过直接调用它绕过此项科学选择。
- 解释新数据前，用sensitivity.py对有依据的不同先验做对照，保留所有结果；不按已知真值命中与否选择先验，不自动扩大先验以让结果通过。报告HPD包含的年份数量、区间数量及先验间总变差距离，不能把MAP稳定或很宽的95%集合含真值说成单年恢复。具体参数由数据来源确定，验证用的20/50/100 BP不是新数据的通用先验。
- 默认拒绝参考不足、导致部分候选位置无法评估的运行。用户确实需要探索性比较时，可显式使用 `--allow-incomplete`，同时报告未评估年份；不能把这些年份当作已排除年代。
- 读取实际 summary.json、posterior.csv、fit_at_map.csv 和 manifest.json 后报告。保留多峰 HPD 集合，说明搜索范围、先验、边界概率及可评估比例。不能只报 MAP 年份，不能把偏移的总体均值±标准差当成正态可信区间。
- 参考缺口、边界集中、稀少候选位置及跨树测试失败都必须披露。计算通过不代表模型适用，更不代表砍伐年、建造年或事件年已经确定。
- 已知年代评分将“命中”“未命中”“真值处参考缺年”“真值在搜索窗外”分开。后两者不能计作覆盖失败或成功；不能把相关窗口数当作独立树木数。13树拼接型参考逐树留出后，可能根本无法在真实位置评分。
- 验证前审查绝对年代如何取得。同一¹⁴C事件匹配确定的遗址年代只能用于发表放置的一致性检验，不能作为该匹配方法的独立准确率证据。不同论文也可能复用同一棵树，例如PNAS2024与Brehm2025的Q4405；不能通过不同文件名或实验室号把它当成整树独立参考。
- 固定偏移时包内按公开重叠积分计算Acomb；单样品似然在所给连续年度参考域归一化，有限参考尾部与搜索先验会改变指标，不能直接宣称与OxCal全模型等价。缺年/搜索未完整评估或共同偏移未知时不硬算该指数。带Delta_R时核对外部Acomb是否属于MCMC前置阶段；最终Amodel/Aoverall保留原名。后验预测频率、残差和偏移收紧都不是Acomb。共有误差仍不受支持，不能拆为独立误差。
- 留一后的MAP变化或小预测尾部面积只提示影响/不相容线索，不自动删样。PPC频率不是频率学p值或统一通过线；模拟数据明确标合成，不作新实测数据或科学准确率。缺参考时只在共同支持上比较，必须同时报告各自共同支持质量。
- 罗马时期（本轮AD46—286）已有系统性未覆盖案例。若待测序列的候选年代涉及该区间，先读验证记录并说明该模型的适用性未通过，不能直接给可靠性结论。IntCal曲线的单年网格不等于原始单年实测；新测量未参与曲线也不保证木材年表或参考树严格独立。

## 入口

需要 Python 3.12 和 NumPy；验证环境为 Python 3.12.14、NumPy 2.3.5。优先使用当前环境已有依赖；缺失时仅在项目允许目录安装，不能写入 C 盘。

单先验计算用 `scripts/run.py`；先验对照用 `scripts/sensitivity.py`；旧后验轻量诊断用 `scripts/diagnostics.py`；六项模型评估用 `scripts/assessment.py`；参考整理用 `scripts/prepare.py`。候选峰包含极小尾部起伏，不能将峰数直接报为等效匹配点数。文件保持自包含，不依赖全局技能安装或 MCP；项目内工具尚未注册全局自动发现。
