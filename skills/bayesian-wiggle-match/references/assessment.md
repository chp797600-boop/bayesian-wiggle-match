# 六项模型评估：0.4.0

用于已有本地运行的稳健性检查与已知年代验证。只读原samples/reference、summary、posterior及manifest；输出到新目录。核心不改，六项检查不自动形成五关全通过结论。

## 入口与身份核对

```text
python -B scripts/assessment.py --run-dir <已有结果目录> --out <新的项目内评估目录> --seed 20261103 --draws 2048
```

程序核对样品/参考散列、当前数学内核身份、参数与保存summary，再按同模型重算并核对最终后验概率和条件偏移。后验概率差容差1e-12、条件偏移差1e-9 BP。发现输入改变或模型不符即拒绝，不把外部软件的不同模型结果移植到本地运行。原输入/输出在评估结束时再次核对散列。

必须显式给seed，默认2048次预测复制。与0.1.0内核相同的历史manifest可核对；任意OxCal JS、人工修改概率或其他模型结果不属于这个入口。内核不匹配时不能靠改manifest散列绕过。

## 1．最终模型的一致性

run和assessment均调用model_checks.fixed_agreement。偏移已固定时，以所给完整连续参考域上每个单样品校准似然f_i(t)归一化，对最终后验q_i(t)计算：

    F_i = sum_t f_i(t) q_i(t) / sum_t f_i(t)^2
    Acomb = 100 exp(sum_i log(F_i) / sqrt(n))
    An = 100 / sqrt(2n)

时间均为同一单位年网格的概率质量。固定非零偏移以已声明值进入似然，不能混入未知偏移模型。保留n、每个Ai、参考域、搜索窗、参考端部似然质量及阈值结果；参考尾部或位置先验截断可能改变指数。所有测年点输入项与复测合并须事先核实。

源参考有缺年、搜索未充分评估或共同偏移未知时，该固定组合指数保留未评估。共享偏移模型仍可执行同模型PPC，提供相容性线索，但PPC不是Acomb替身，也不是完成了最终OxCal指数验收。外部Amodel/Aoverall/Acomb需保留模型与阶段身份。

两个解析正态控制及54个官方OxCal导出分布核对支持重叠积分实现；它们不证明本地有限年度参考、BP空间、搜索先验等整体与OxCal等价。例如本地Jermyn固定零偏移Acomb约52.32%，官方既有设置为52.8%，不调整数据追求一致。

## 2．逐轮留一与留出预测

每次删除一个测量再拟合，记录MAP、HPD、偏移及概率变化。删除最早测量时将保留年距归零，同时平移搜索范围，输出再平移回原序列起点。原序列少于3个点时不做留一，不把不受支持的一点模型包装为有效结果。

支持相同才报告直接TV；支持不同时只报告共同位置上重新归一化的条件TV，并同时给双方共同支持概率质量，不能用零填补未知位置。留出测量的预测包括测量方差、该年参考方差及保留数据估计的共同偏移不确定度；留出年参考缺失时报告可预测质量及条件状态。

留出CDF、双尾面积及预测对数密度只是诊断。影响大的点可能是真实关键事件，也可能有测量/年距问题；不自动删样，不用真值决定删谁。

跨多个点取最小尾部面积属于多重检查，不能直接当作校正后的显著性结果。MAP位移很大也可能只是竞争峰排序变化，须同时读HPD和概率质量/TV，不解释为整个后验都移动了同样年数。

## 3．后验预测检查

从最终p(T)抽日历位置，再抽该位置的条件delta；每次整段共享一个delta，按原有效高斯方差s_i²+c_i²生成复制数据。比较观测和复制数据的标准化残差平方和、最大绝对值、相对实际年距的趋势及最长同号串。保存每次统计量、合成复制值、预测边缘均值/标准差/等尾95%区间。

预测复制的是当前有效误差模型，不是对同一物理年轮进行重复实验。参考跨年相关和批次共有误差仍不支持。后验预测上尾频率P(T_rep≥T_obs|data)附Monte Carlo标准误，不是频率学p值、模型正确概率或Acomb；没有通用0.05通过开关。数据参与拟合会影响这些频率的解释，必要时结合真正留出预测。

## 4．搜索与参考对照

```text
python -B scripts/assessment.py --run-dir <旧结果> --out <新评估目录> --seed 20261103 --expanded-start-min <较早起点> --expanded-start-max <较晚起点> --reference-alternative <另一参考CSV>
```

扩展边界必须同时提供并包含原搜索范围。替代参考参数可重复，保持原测量、位置窗和偏移先验。每种设定保留完整后验、HPD、MAP和覆盖；报告扩展后位于原窗外的概率。没有提供对照设置时明确未执行，不生成看似已通过的敏感性结果。

替代参考须有真实标识并排查同树/同测量重叠。无可评估位置则记未评估，不填成功或失败。共同支持条件TV须结合共同质量和参考覆盖；不能与全搜索范围TV混为一谈。不同来源的差异不自动归因于区域偏移，插值逐年不等于原始年度实测。

## 5．年代—偏移联合摘要

run自动保存混合均值/标准差、等尾95%区间、先验/后验标准差比、年代与偏移协方差/相关性及年代间条件均值变化贡献的偏移方差比例。等尾区间不是HPD，多峰不能只报均值±标准差。固定偏移的收紧比/相关性留空，不写无限。物理解释仍需独立对照；先验敏感性继续使用sensitivity.py，不能只看MAP。

## 6．独立真值与模型内覆盖

`--truth-start <独立已知起点>`只在所有设定固定后评分，须自行核对独立来源。没有独立真值记不适用；真值处无参考或窗外另列，不算覆盖失败。事件自匹配日期不是独立真值。

`--simulation-replicates 256`显式开启模拟：T均匀抽自可生成的候选位置（不是从实测后验抽），delta从声明先验抽，按同一有效误差模型生成并保存合成测量，随后重新拟合。真实T/delta只用于评分，不传给推断或挑选模型。报告95%和95.45%离散HPD覆盖、实际后验质量、区间年数和Wilson95%蒙特卡洛区间；离散HPD实际质量可能高于标称值。

这是模型内覆盖核查，不是新实测数据、完整SBC秩检验、或独立考古准确率。真实数据模型失配可在理想模拟看似正常时仍存在，不能以模拟覆盖代替独立年表验证。

## 输出与范围

assessment.json包含完整设定、来源/代码散列、六项结果及限制；leave_one_out.csv、predictive_marginals.csv、predictive_statistics.csv和按需simulation_runs.csv便于核查。assessment.json保留留一/对照后验及合成数据。默认不启动参考替换或模拟，也不改变原来的拟合。

共有误差、不确定年距、多年混样仍须另建有依据的模型，本版不自动添加协方差或误差膨胀。没有自动删样、自动先验选择、科学唯一性或五关全通过结论。

方法依据：[OxCal一致性定义](https://c14.arch.ox.ac.uk/oxcalhelp/hlp_analysis_detail.html)、[Stan后验预测说明](https://mc-stan.org/docs/stan-users-guide/posterior-predictive-checks.html)、[Stan模拟校准说明](https://mc-stan.org/docs/stan-users-guide/simulation-based-calibration.html)。本版使用NumPy独立实现，不依赖Stan，也不是OxCal作者代码封装。
