# 本项目MCP初选流程

当前定位是初选：寻找候选年代带、识别覆盖和模型问题，不能自动给出可靠绝对年代、砍伐年或事件年。

建议配置的本地服务ID为 `bayesian_wiggle_match`。优先使用当前工具列表中该服务的实际工具名称；不同客户端可能加前缀，不假设名称一定无前缀。服务提供list_reference_data、get_reference_info、validate_floating_series、run_wiggle_match、assess_match。

1. 首先确认输入是单年树轮的常规14C BP、1σ、相对轮位和可追溯身份；有缺测按准确年距保留，不能补造测量。通过validate_floating_series核查结构。
2. 用list_reference_data列出包内真实单年参考，再逐条get_reference_info审查年代依据、地区/生长季/实验过程、覆盖与物理树共享关系。先用可靠日历年代实测段；插值参考不是单年实测。七份参考/494年度点仅局部覆盖，不是全时段全地区参考库。
3. 不能把库外或缺年位置当作已排除，不能默认混合多棵树或选最窄的一次结果。不同参考分开记录；没有合适参考时给出具体缺口。
4. run_wiggle_match必须明确reference_id、start_min/start_max、offset_mean_bp、offset_sd_bp和未用run_id。位置界限为最早实测轮的天文整数年。用户未给合理偏移依据时不能把旧示例50 BP当已验证先验；只有明确标记的探索对照可以使用事先声明的假设组，不能按真值挑参数。
5. 参考覆盖不足默认拒绝；仅在有明确探索需要时使用allow_incomplete=true，并在输出最前面标明条件化。按需assess_match保存留一/PPC；它们不是最终共享偏移Acomb替身。
6. 初选报告列所有主要候选年代带与概率、所用参考/来源、先验、搜索覆盖、HPD/局部窗概率、敏感性和未解决项。沿用五关分项状态，未评估不写通过。未知样品第五关不适用，不以此推断准确性。

如果服务工具未出现在当前列表：明确告知需要按仓库README配置客户端连接，提示重开本项目或重新加载客户端。不要声称已调用MCP，不以缓存示例伪造结果。必要的本地脚本备用调用须说明并记录与实际MCP调用的区别。

包内完整启动与数据说明：[本地MCP使用说明](../../../README.md)。计算内核和科学限制保持原版本，不以安装或初选过线升级可靠性声明。所有原始样品、输出和缓存均留在项目，禁止上传及写C盘。
