- 实际树木测试的每个可运行案例还用稠密协方差求解独立计算全部年份概率，与解析内核的最大差小于 2e-14。此为同一模型的独立数值路径核对，不是作者软件复现。
- CLI 默认在任何候选起点因参考缺年而无法评估时拒绝运行；只有显式 allow-incomplete 才生成条件化探索结果。任何高后验仍条件于用户给定搜索窗。

## 数据整理

最终库含 2,576 条测量、30 个保守树木/来源组。消除 127 次跨文件重复导入；588 行导入实例列入排除记录（同一测量的重复导入可能重复计入排除行，不能视为588个独立样品）。原始未过滤阶段的 2,850 条库和初轮结果仅是过程证据；不能当最终库使用。

本次仅标准化六份 IntChron JSON 与 Brehm 2021 PANGAEA 13个年度子表。其余已下载数据仍保留原样，未声明全部进入可计算库。r_date_sigma_batch 非零记录明确排除，不擅自把共有误差加到独立误差中。
